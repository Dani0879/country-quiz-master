# Unit Tests for Country Quiz

## Test Files

1. **QuizContext.test.jsx** - Tests for context state management
2. **Quiz.test.jsx** - Tests for Quiz component logic
3. **Home.test.jsx** - Tests for Home component
4. **Results.test.jsx** - Tests for Results component

## Run Tests

```bash
npm test
```

## Run Tests with UI

```bash
npm run test:ui
```
